## What this records

The earlier Eye Detected work explored global DR grading with a global CE branch, a global CORAL branch, and a
DINOv3 patch Attention MIL + CORAL branch. The prior handoff reported development QWK around **0.682** for the old
C2 branch. Other historical values such as 0.668 and 0.587 may appear in prior handoff material. They are retained as
context, not re-presented as measurements made by the current OcuForge V3 repository.

The earlier work was oriented toward DDR/IDRiD-style comparison and included preserved or unrun sealed/external gates
depending on the artifact. Its labels, splits, preprocessing, model revisions, and evaluation status are not the V3
MMRDR-UWF R1 contract.

## Why it informed V3

The old work supports preserving DINOv3 patch geometry and Attention MIL as a reusable implementation family and as
one scientifically distinct hypothesis. It does not establish that DINOv3 wins, that attention localizes lesions, or
that CORAL should be the initial objective. V3 therefore compares exactly C0, C1, and C2 with CE first, then reserves
a winner-only CE versus CORN ordinal ablation.

## Claim boundary

These values are historical engineering/benchmark evidence from a different experiment context. They are not a current
R1 result, not a champion declaration, not external generalization, not clinical validation, and not a deployment
recommendation. Do not use the old values to infer current data eligibility, model selection, or phase completion.
